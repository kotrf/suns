## Не открывать повторно по старым сводкам

Первоначальные три AI-фазы #188/#189/#190, colony plans #201/#207, первая Stargate Specialist, paid depot/relay #214/#215 и шесть исправлений аудита #216 уже документированы в main. Старые статусы «не реализовано»/«PR открыт» были верны для своего момента.

Дальнейший GameSession #47 и UI acceptance #94 остаются техническими продолжениями handoff; это не новые игровые механики. Конкретный crash из старой версии заново воспроизводить, прежде чем считать текущим дефектом.

Про браузерный порт найден только [запрос оценки](fragments/browser-port.md), принятого переноса нет. Не включать его в согласованный roadmap.

## Пробелы источников

Полных отдельных выжимок #02/#03/#08 в проверенной ветке пока нет. Даже новые карточки частично используют сжатый handoff и не содержат всех ранних ответов; точные мотивы и числовой баланс не додумываются. Подробности — [INDEX](INDEX.md), [SOURCES](SOURCES.md).
