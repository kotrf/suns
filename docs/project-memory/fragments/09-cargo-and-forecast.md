# Фрагменты — Dialog #09

Начало: 13 октября 2026, продолжения найдены 15–16 октября. Полного текста и ID нет. [V10](../SOURCES.md#v10), [R13](../SOURCES.md#r13)

## Решения и мотивы

Пользователь описал расхождение после Queue: остаток населения в System неверен, повторно открытый Transfer Cargo показывает пустой корабль. Он предложил показывать обе стороны обмена — трюм и поверхность/другой корабль — с ползунками. Нужно видеть уже намеченные переносы, а не терять собственное намерение при повторном открытии. [V10](../SOURCES.md#v10), [R13](../SOURCES.md#r13)

Прогноз населения не должен симулировать целый год. Достаточно текущего населения и процента роста; после погрузки пересчитать базу. Причина пользователя: на реальный следующий год влияет слишком много факторов, моделировать будущую разгрузку транспорта в этом прогнозе избыточно.

Диагноз «предпросмотр запускал полный ход» дал ассистент; его нельзя оформлять как установленную пользователем причину дефекта. [R13](../SOURCES.md#r13)

Transfer Cargo должен определять систему из подтверждённой орбиты выбранного флота, без отдельного клика по звезде. Старое/расчётное положение недостаточно для непосредственного обмена. [R14](../SOURCES.md#r14), [D06](../SOURCES.md#d06)

## Уточнение связи

Поздние реплики требуют физично разделить приём и передачу: Passive слушает без телеметрии, а на своей орбите системе доступен полный статус флота, который она пересылает через свою связь. Более раннюю формулу «прибытие по радару» не считать запретом полного локального обмена. Точный contract — [communications](../../communications.md). [R15](../SOURCES.md#r15)

## Незавершённое и границы

Числовые варианты массы колонистов в неполных воспоминаниях не фиксируются как окончательное решение; текущие единицы — в [cargo-manifest](../../cargo-manifest.md). Точная финальная версия UI, все предложения про шаблоны колоний и обнаружитель медленного передатчика требуют исходной беседы. Последний остаётся обсуждением #205 по [status](../../project-status.md).
