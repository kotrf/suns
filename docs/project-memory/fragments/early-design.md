# Ранние неатрибутированные фрагменты — 17–19 августа 2026

Это одна группа найденных реплик, а не доказанный отдельный чат. Связь с [Dialog #01](../dialogues/01-stations-communications-and-unique-mechanics.md) не установлена.

17 августа поиск возвращает принятый ориентир: дух Stars! с современной реализацией, без перегруженного 4X; механика должна создавать стратегическое решение. Первичный текст и точный заголовок отсутствуют. [R01](../SOURCES.md#r01)

18 августа принят ранний ограниченный стартовый Warp, а W9/W10 оставлены технологиям. Позднее пользователь открыл выбор до W10 с предупреждением о overdrive; не путать доступный выбор с безопасной скоростью двигателя. [R02](../SOURCES.md#r02), [#03](03-interface-and-orders.md)

19 августа: цветные mineral gauges, fuel/cargo indicators, читаемый стиль и View перед Help; отдельный Transfer dialog тогда отложен. Это историческое откладывание: нынешний грузовой UI уже существует, его не нужно заново начинать. [R03](../SOURCES.md#r03), [#09](09-cargo-and-forecast.md)

Нельзя назначать этой группе номер #01 или выводить личные причины из готового design.md. Пакет поздних уникальных механик и причины из самого первого сохранённого диалога читать отдельно в C01.
