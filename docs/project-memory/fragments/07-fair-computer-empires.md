## Решение и собственная причина пользователя

Сергей вспомнил, что параметры компьютерных рас Stars! выходили за ограничения мастера создания рас для человека. Он предпочёл честного соперника, хотя признал сложность реализации.

Принят порядок: **станции и защита колоний → разведка и РЭБ → компьютерный игрок**. Реализация и merge этого пакета прямо разрешены. Это историческое поручение, а не разрешение сливать все будущие PR.
