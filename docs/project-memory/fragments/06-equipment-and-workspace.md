## Принятые направления и причины

Для двигателей пользователь предложил сначала взять типы, количество и уровни Stars!, затем свои вариации. Wormholes должны обнаруживаться, а не просто быть известными: разная заметность и возможный специальный радар — направление дальнейшей проработки. Числа и весь список датчиков этим не заморожены. [R09](../SOURCES.md#r09)

После изменения Warp выбранного участка таблица должна обновляться; нужен расход/остаток топлива по участкам, чтобы маршрут был понятен. Точный UX за рамками найденного запроса не додумывается. [V07](../SOURCES.md#v07)

Designer и History/graphs — отдельные окна без docking, Research тоже отдельным окном. Причина для Designer: docking давал непонятное поведение виджета. Hab-звёзды нужны крупнее, поскольку даже родная система с 100% выглядела мелкой. Это не просьба отменить все рабочие панели. [V07](../SOURCES.md#v07)

На стадии прототипа старые save-файлы можно не поддерживать. Это разрешение упростить разработку, не поручение немедленно удалить все legacy-правила. Основание уточнено прямой репликой в этой беседе: «можно для упрощения пока не делать обратную совместимость файлов сохранения». Другие диалоги не нужны для атрибуции этого разрешения.

## Исторический статус

Внутри беседы прямо видны поручения взять корпуса и модули Stars!, ресурсы/производственную очередь для терраформинга, автоматические повторяющиеся пункты (пример: 10 фабрик ежегодно), постоянные панели колонии и русский список задач Notion. Полная карточка разделяет эти решения, предложения ассистента и неизвестное содержание ранних ответов. Сравнительная мотивировка выбора корпусов отдельно пользователем не названа.

Последний подтверждённый рабочий результат — [merge #179](https://github.com/kotrf/suns/pull/179), графики боевых потерь в History и [50/50 CI main](https://github.com/kotrf/suns/actions/runs/38162625392) 11 октября. #178 закрыта; #48 оставлена открытой. Это историческая граница, не описание сегодняшнего состояния. Детали учёта потерь по получению отчёта — реализация ассистента; ранние численные решения и три недоступных снимка не восстановлены.
