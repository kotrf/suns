# Фрагменты — Dialog #06

Видимое начало: 2 октября 2026. Доступны фрагменты и поисковые пересказы; конец беседы не установлен. [V07](../SOURCES.md#v07), [R09](../SOURCES.md#r09)

## Принятые направления и причины

Для двигателей пользователь предложил сначала взять типы, количество и уровни Stars!, затем свои вариации. Wormholes должны обнаруживаться, а не просто быть известными: разная заметность и возможный специальный радар — направление дальнейшей проработки. Числа и весь список датчиков этим не заморожены. [R09](../SOURCES.md#r09)

После изменения Warp выбранного участка таблица должна обновляться; нужен расход/остаток топлива по участкам, чтобы маршрут был понятен. Точный UX за рамками найденного запроса не додумывается. [V07](../SOURCES.md#v07)

Designer и History/graphs — отдельные окна без docking, Research тоже отдельным окном. Причина для Designer: docking давал непонятное поведение виджета. Hab-звёзды нужны крупнее, поскольку даже родная система с 100% выглядела мелкой. Это не просьба отменить все рабочие панели. [V07](../SOURCES.md#v07)

На стадии прототипа старые save-файлы можно не поддерживать. Это разрешение упростить разработку, не поручение немедленно удалить все legacy-правила. Независимо подтверждается [C01](../SOURCES.md#c01) и поздним [handoff](../../project-status.md).
