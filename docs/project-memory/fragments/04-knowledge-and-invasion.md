# Фрагменты — Dialog #04

Видимое начало: 6 сентября 2026. Полного транскрипта нет. Поисковая метка «Dialog #04» от 29 августа неоднозначна и сюда автоматически не включена. [V05](../SOURCES.md#v05), [R06](../SOURCES.md#r06)

## Решения и причины

Пользователь запросил Rename для флота и возраст последнего сканирования системы. Причина возраста сформулирована явно: система могла уже стать чужой, а без нового наблюдения игрок этого не знает. Дата сведений должна быть доступна в интерфейсе.

Выбрано запретить мирную колонизацию уже занятой планеты: сначала завоевание. В качестве ориентира пользователь описал выгрузку колонистов и наземный бой Stars!, включая неопределённость исхода. Точная формула боя этим воспоминанием не утверждена. [V05](../SOURCES.md#v05)

## Предпочтения и пробелы

Из-за неполной видимости длинного чата на Android пользователь попросил сохранять контекст и в Notion, и в GitHub перед переходом в новый диалог.

Следующая задача в видимом фрагменте не названа; не восстанавливать её по порядковому номеру PR. Современный ground-invasion код нельзя автоматически считать полным повторением вспомненной формулы Stars!.
