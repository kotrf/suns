# Фрагменты — Self hosted runner

Видимое начало: 20 августа 2026. V14 относится к именованной беседе; более поздние R10/R11 связаны тематически, их принадлежность именно этому чату не доказана. Полного актуального инвентаря хостов здесь нет.

## Решения и причины

Пользователь напомнил сделать backup, когда snapshots провайдера не работали. После ошибки GPG сообщил об успешной проверке backup, решил перенести файл и вернуться к snapshots позже. Это подтверждает проверку архива по его сообщению, но не фактический test restore. [V14](../SOURCES.md#v14)

9 октября: переход к ephemeral runner, старый работающий CI не отключать до проверки замены. 11 октября: принят отдельный official/portable Qt PR, домашний runner остановлен; пользователь снова напомнил backup перед окончательным переводом. Это последовательные исторические состояния, не противоречивые текущие инструкции. [R10](../SOURCES.md#r10), [R11](../SOURCES.md#r11)

## Открытое

Не восстановлены окончательная snapshot-политика и место/срок хранения проверенной копии. Нельзя выдавать старые имена eve/home/ephemeral за сегодняшний runner: [project-status](../../project-status.md) на 17 октября называет suns-vps / Qt 6.12.0. Текущие live-хосты этим docs-only проходом не проверены.
