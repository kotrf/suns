# Фрагменты — Dialog #02

Видимое начало: 25 августа 2026. Это частичная реконструкция по V03, R04–R08; не локальная выжимка полного исходного диалога. [Основания](../SOURCES.md#v03)

## Решения и причины

Пользователь предпочёл оставить собственный self-hosted runner: у GitHub-hosted есть ограничения бесплатного использования, а suns-eve находится под его контролем. Публичный репозиторий допустим; позже пользователь сообщил о переводе в public. Текущие тарифы и настройки этим архивом не проверяются. [V03](../SOURCES.md#v03)

Чужие fork PR не должны запускать недоверенный код на собственном runner; публикация веток/PR отдельно разрешена. Точные ранние метки чатов противоречивы, поэтому эти поисковые реплики связаны тематически, а не объявлены целиком частью #02. [R06](../SOURCES.md#r06), [R07](../SOURCES.md#r07)

В найденной реплике 25 августа принят гибридный обзор: ordinary scanner даёт контакт, penetrating — данные планеты на пролёте, иначе требуется орбита. Самостоятельная причина этого выбора в пересказе не раскрыта. [R04](../SOURCES.md#r04)

## Отложенное и пробелы

Расовый penetrating hull/технология тогда отложены; это историческая отметка, а не доказательство отсутствия нынешних сканеров. Раннее разрешение несовместимости save найдено отдельно и не привязано уверенно к этому чату. [R05](../SOURCES.md#r05)

Не восстановлены полный перечень принятых GitHub-настроек и все игровые решения беседы. Действующие CI и merge-правила смотреть в [project-status](../../project-status.md); исторический запрос объяснить настройки не является разрешением произвольно менять их сегодня.
