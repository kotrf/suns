## Важные изменения, которые нельзя сплющивать

- В #04 предлагали 100 кг на колониста. Поздняя #09 и текущий [cargo contract](../cargo-manifest.md) описывают **100 колонистов на kt**. Это разные этапы баланса; раннее число не возвращать автоматически.
- Раннее ограничение стартового Warp и поздний выбор UI до W10 совместимы только с различием safe/overdrive; выбор скорости не делает двигатель безопасным.
- Старые первые шаги AI, gates и colony plans уже выполнены по [актуальному checkpoint](../project-status.md). Упоминание в исторических вопросах не открывает их заново.
- Числа радиусов, цен и лимитов — текущая реализация, пока не доказано отдельное устойчивое пользовательское требование.
- Рассмотрение браузерного порта, нового сканера или политики эвакуации ещё не означает поручения их реализовать.
