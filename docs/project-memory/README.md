# Память решений Suns!

Здесь сохраняются причины решений, отвергнутые и отложенные варианты, предпочтения и вопросы из разговоров Сергея о **Suns! / kotrf/suns**. Текущее состояние реализации — в [project-status](../project-status.md); этот архив дополняет его историей выбора.

Срез инвентаризации: **18 октября 2026, MSK**. Это частичный архив, не экспорт проекта ChatGPT. Полного списка и текстов всех чатов нет.

## Как читать архив

**V** — реплика видна в переданном контексте; старый чат всё равно может быть обрезан. **R** — поиск вернул исторический пересказ с timestamp; это не дословная цитата и не полный транскрипт. **C** — уже опубликованная выжимка из конкретного чата, прочитанная как документ. **D** — документ репозитория, подтверждающий описание реализации, а не личную мотивацию.

Решение пользователя, его предпочтение, предложение ассистента и вывод автора должны оставаться различимыми. Неизвестная причина остаётся неизвестной. Одобрение brainstorming-направления не утверждает все его числа и детали.

Старое «отложено» не обязательно означает открытую задачу сегодня. Верхние датированные записи [project-status](../project-status.md) и актуальные тематические документы имеют приоритет над историческими checkpoint-разделами; например, первоначальные три фазы AI уже завершены, хотя нижние разделы всё ещё описывают первый срез.

## Как дополнять из исходных диалогов

1. В каждом чате составить выжимку **только его собственной доступной переписки**: решения и причины; отложенные идеи; ограничения/предпочтения; открытые вопросы.
2. Указать название, известные даты, доступность ранней части и авторство утверждений. Не придумывать ID/URL чата.
3. Сначала прочитать актуальную ветку `codex/project-memory-inventory` в **kotrf/suns**. Дополнить существующий файл этой беседы в `dialogues/` либо создать новый с устойчивым именем.
4. Сверить соответствующий файл `fragments/`. Не принимать его за первичный источник; исправить расхождения или связать с более полной карточкой через реестр.
5. Сохранить коммит в этой ветке, учитывая её текущую вершину. Завершать совместную правку реестра по свежему состоянию ветки; не затирать соседние выжимки.
6. После обхода чатов отдельно свести дубли, изменения решений и актуальность открытых вопросов.

Архив не является разрешением на реализацию всех перечисленных идей или автоматический merge. Действующие поручения пользователя применяются в своей области; исторические условия не заменяют свежие указания.

В поиске встречались нерелевантные проекты, эхо текущих запросов и неоднозначная нумерация. Они исключены из свидетельств Suns!. Сырые выдачи поиска и личные темы сюда не сохранялись.
