# Архив решений Suns!

Для начала нового диалога или работы с кодом читать **[PROJECT_CONTEXT](../PROJECT_CONTEXT.md)**. Это отфильтрованная суть проекта: цели, устойчивые решения с причинами, проверенный текущий срез и ближайшие направления. Весь архив при старте читать не нужно.

| Потребность | Файл |
| --- | --- |

## Что сохранено

Карточки в `dialogues/` — исторические выжимки, сделанные внутри бесед. Они сохранены без редактирования при фильтрации 18 октября 2026. В них есть технические отчёты, старые TODO и подробные оговорки; это материалы для адресного обращения, а не стартовый briefing.

Поисковые фрагменты уступают карточкам по надёжности атрибуции. Для #04/#05/#06/#07/#09/#10 дублирующие фрагменты свёрнуты в ссылки. Для #02/#03/#08 пока найдены только фрагменты; не называем комплект полным экспортом всех диалогов.

Runner/Qt вынесены из основной памяти. Исторические номера запусков, ошибки установки, успех отдельных тестов и старые разрешения merge не нужны для понимания игры. Актуальные правила сборки — в README и workflow; исторические инструкции эксплуатации не применять вслепую.

## Как отличать память от факта

- **V** — доступная реплика/часть переписки; **R** — поисковый пересказ; **C** — сохранённая выжимка чата; **D** — документ реализации. У новых карточек есть собственные обозначения источников в [SOURCES](SOURCES.md).
- Принятое решение пользователя, предложение ассистента и вывод по коду не равнозначны. Общий brainstorming не утверждает все цены и формулы.
- «Не восстановлено здесь» не означает «не реализовано». Исторические next steps проверять по свежему main и [status](../project-status.md).
- Сохранённая история не является новым поручением, разрешением merge или доказательством ручной приёмки.

При появлении новой сводки обновить реестр, затем перенести в короткий контекст только то, что меняет устойчивый смысл проекта. Не добавлять туда хронику PR, повторяющиеся ограничения и весь backlog. Сначала проверять актуальную вершину ветки, чтобы сохранить соседние дополнения.
