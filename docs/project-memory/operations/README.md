## Решения рабочего процесса вне игровой памяти

- **MEM-07:** исторический выбор собственного self-hosted runner; чужие fork PR не исполнять на доверенном хосте. Названные тогда причины — контроль над своим сервером и ограничения внешнего CI. Это не проверка современных тарифов или настроек. [V03](../SOURCES.md#v03), [R06](../SOURCES.md#r06).
- **MEM-08:** backup перед окончательным переводом CI, проверка замены до отключения рабочего варианта. Даты и изменения состояния — в [карточке](self-hosted-runner.md). Проверенный архив не равен test restore.
- **MEM-19:** сохранять контекст между чатами в GitHub/Notion из-за неполной видимости длинных разговоров. Это причина появления архива, не игровая механика. [Notion](../fragments/notion.md).
- В ранних беседах merge разрешали отдельно; в #09/#10 пользователь подтвердил применение auto-merge к подготовленным PR при сохранённых проверках. Старые сообщения не заменяют действующее поручение и не означают автоматическое слияние любой новой работы. [#09](../dialogues/09-colonization-radars-cargo-and-forecast.md), [#10](../dialogues/10-large-roadmap-and-deep-space.md).
